# Security Policy

## Supported Versions

XDrive Logistics is currently under active development.

| Version | Supported |
| ------- | --------- |
| Current production release | Yes |
| Current staging / preview release | Yes |
| Older or superseded releases | No |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub Issues.

Report suspected vulnerabilities privately by email:

contact@xdrivelogistics.co.uk

Please include:

- a clear description of the vulnerability;
- the affected page, API route, mobile flow or database function;
- steps required to reproduce the issue;
- screenshots, logs or proof-of-concept details where appropriate;
- the potential security impact;
- your contact details.

We aim to acknowledge valid reports within 3 business days and provide an initial assessment within 7 business days.

Please allow us reasonable time to investigate and remediate the issue before public disclosure.

## Scope

This policy applies to:

- xdrivelogistics.co.uk;
- XDrive Logistics web applications;
- XDrive Driver mobile application;
- public and authenticated APIs;
- Supabase database functions, storage and access-control policies;
- authentication and onboarding flows.

## Out of Scope

The following are generally out of scope unless they demonstrate a real security impact:

- automated scanner reports without verification;
- denial-of-service testing;
- social engineering;
- attacks against third-party services not controlled by XDrive Logistics;
- issues requiring physical access to a user device.

## Responsible Disclosure

Researchers must:

- avoid accessing or modifying other users' data;
- avoid disrupting production services;
- stop testing immediately if sensitive data is exposed;
- report findings privately and in good faith.
