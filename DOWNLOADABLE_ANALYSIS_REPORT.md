# Raport descărcabil — XDrive Logistics

## Rezumat
Acest document a fost creat ca versiune descărcabilă a unei analize scurte despre repository.

## Proiect
- Nume: XDrive Logistics Ltd website
- Framework principal: Next.js 15
- UI: React 19
- Limbaj: TypeScript
- Stilizare: Tailwind CSS
- Componente: Radix UI
- Validare formulare: React Hook Form + Zod
- Backend / date: Supabase

## Structură principală
- `/app` — pagini și layout-uri Next.js App Router
- `/lib` — utilitare și logică partajată
- `/database` — referință SQL consolidată
- `/supabase/migrations` — istoric migrări Supabase
- `/public` — fișiere statice
- `/middleware.ts` — middleware de securitate / request handling

## Scripturi disponibile
- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run lint`
- `npm run typecheck`

Dacă vrei, la următorul mesaj pot genera un raport mult mai mare în același format și îl pot salva din nou ca fișier descărcabil.
